1. DESCRIPTION OF APPLICATION
================================================================================

The Application is a tool designed to assist users in evaluating the accessibility
of web pages. It utilises browser automation (Puppeteer) to navigate websites
and accessibility testing engines (Axe-Core) to analyse content against selected
accessibility standards (e.g., WCAG). It generates reports based on these
automated checks.

The Application is currently in active development (beta). This means core
features may be missing, incomplete, or subject to significant change. Features
may be unstable or prone to errors, and data formats (such as saved configuration
files) may change between versions without backwards compatibility. Users are
